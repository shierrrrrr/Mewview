# Mewview（瞄瞄）用户指南 User Guide

## 打开图片

- **文件对话框**：点击「打开」或按 `Ctrl + O`
- **拖拽**：把图片文件拖入窗口
- **剪贴板**：复制一张图片后，在窗口内按 `Ctrl + V`
- **命令行**：`Mewview.exe <图片路径>`

支持的格式：JPG / JPEG / PNG / WEBP / BMP / TIFF（含多页）/ GIF（含动图）/ ICO / JPEG XR（.jxr、.wdp）/ HEIC（.heic、.heif）/ AVIF。

多页 TIFF 用 `PageUp` / `PageDown` 翻页，动图 GIF 会自动播放；这类多帧图片只能查看，不参与标注与裁剪。

HEIC / AVIF 由 Windows 的**可选解码扩展**提供解码能力（Microsoft Store 免费）。未安装时打开会提示需要安装哪个组件，程序自身既不联网下载也不安装任何东西。

## 浏览与缩放

- **上一张 / 下一张**：`←` / `→`（浏览当前目录下的图片）
- **缩放**：滚轮（以光标为中心缩放）
- **平移**：按住左键拖动
- **适应窗口**：`Ctrl + 0`；**实际大小**：`Ctrl + 1`；**切换**：双击

## OCR 识别文字

1. 点击顶部 OCR 图标或按 `Ctrl + E`，展开 OCR 面板并开始识别
2. 首次使用会询问是否下载模型（约 36 MB，仅一次）
3. 识别结果在右侧面板显示，可一键复制全部文字
4. 可在面板顶部的语言下拉框切换「中文 + English / 한국어」

> OCR 完全本地运行，图片与文字不会上传。

## 标注与裁剪

- 左侧编辑栏选择工具：画线、箭头、矩形、文字、裁剪
- 绘制后按 `Esc` 退出当前工具
- 裁剪：框选后确认（Enter）或取消（Esc）

## 保存

- **保存（覆盖）**：`Ctrl + S`
- **另存为**：`Ctrl + Shift + S`
- 编辑是非破坏性的，原图不会被自动覆盖

## 置顶

- 点击图钉按钮或按 `Ctrl + Shift + Space`，窗口保持在最上层；再次点击取消。

## 复制 / 粘贴

- 复制当前图片到剪贴板：`Ctrl + C`
- 从剪贴板打开图片：`Ctrl + V`

## 右键菜单

在图片区域右键可快速访问：打开、复制图片、OCR、裁剪、另存为、置顶、适应窗口、100%、关闭。
