# 键盘快捷键 Keyboard Shortcuts

## 全局快捷键

| 操作 | 快捷键 |
|---|---|
| 打开图片 | Ctrl + O |
| 从剪贴板打开图片 | Ctrl + V |
| 复制图片到剪贴板 | Ctrl + C |
| 保存（覆盖原图） | Ctrl + S |
| 另存为 | Ctrl + Shift + S |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Y |
| 上一张 | ← |
| 下一张 | → |
| 适应窗口 | Ctrl + 0 |
| 实际大小（100%） | Ctrl + 1 |
| 窗口置顶 / 取消置顶 | Ctrl + Shift + Space |
| 打开 / 收起 OCR 面板 | Ctrl + E |
| 退出当前工具 / 关闭图片 | Esc |

## 鼠标交互

| 操作 | 方式 |
|---|---|
| 缩放 | 滚轮（光标位置锚定） |
| 平移 | 左键拖拽 |
| 100% / 适应窗口 切换 | 双击 |
| 右键菜单 | 右键点击图片区域 |

> 注：当文本框（OCR 结果框、文字标注编辑器）获得焦点时，所有按键输入属于该文本框，快捷键不生效。
