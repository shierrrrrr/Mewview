# 已知问题 Known Issues

以下为当前版本（0.1.0）已知的问题与限制。

## 性能与内存

- **超大图片**：超过约 1600 万像素的图片会按尺寸降采样解码以限制内存占用；放大超过 100% 时可能无法显示原始全分辨率细节。
- 图片查看器会为当前图片保留解码后的位图，处理多张大图时内存占用较高。

## OCR

- OCR 准确率受图片质量、字体大小、背景复杂度影响；小字体与复杂背景的识别效果可能不理想。
- 首次使用需联网下载模型（约 36 MB），之后完全离线。

## 其他

- 文字标注（Text）的编辑能力较基础。
- 高亮（Highlight）、模糊/马赛克等标注工具尚未实现（规划于后续版本）。

## 报告问题

如遇到问题，请通过 GitHub Issues 报告，并尽量附上：

- Mewview（瞄瞄）版本
- Windows 版本
- 复现步骤
- 截图或错误日志（`%TEMP%\mewview_error.log`）
