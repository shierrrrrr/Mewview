# 已知问题 Known Issues

以下为当前版本已知的问题与限制。

## 性能与内存

- **超大图片**：超过约 1600 万像素的图片会按尺寸降采样解码以限制内存占用；放大超过 100% 时可能无法显示原始全分辨率细节。
- 图片查看器会为当前图片保留解码后的位图，处理多张大图时内存占用较高。
- **多页 TIFF 翻页可能短暂停顿**：打开时只解码第 1 页（这一步在后台完成，不阻塞窗口），之后每页在翻到它时才解码，单页很大的扫描件翻页会有一瞬卡顿。

## OCR

- OCR 准确率受图片质量、字体大小、背景复杂度影响；小字体与复杂背景的识别效果可能不理想。
- 首次使用需联网下载模型（约 36 MB），之后完全离线。

## 图片格式

- **多帧图片不支持标注**：多页 TIFF 与动图 GIF 只能查看与翻页／播放，缩放、平移、OCR 不受影响。
- **HEIC / AVIF 依赖系统解码扩展**：这两种格式由 Windows 的可选组件解码，未安装时无法打开（程序会说明需要安装哪个组件）。程序自身不联网、不安装任何东西。
- **HEIC 的透明通道会丢失**：Windows 的 HEIF 解码器返回不带 alpha 的位图，带透明区域的 HEIC 会显示为不透明。
- **HEIC / AVIF 色度按 BT.709 解释**：若文件把色度矩阵标记为 BT.601（部分编码器会这样写），饱和色会出现轻微偏色。相机与手机产出的文件通常是 BT.709，不受影响。
- **动图 WebP 只显示首帧**：不播放动画。
- **严重损坏的 HEIC** 可能被系统解码器解成 1×1 而不是报错。

### 方向元数据

- 解码器不会按 TIFF 的 `/tiff/Orientation` 自动旋转，部分手机或扫描仪产生的图片方向可能不正。
- 同理，带 EXIF 旋转标记的 JPEG 也不会自动旋转。

## 其他

- 文字标注（Text）的编辑能力较基础。
- 高亮（Highlight）、模糊/马赛克等标注工具尚未实现（规划于后续版本）。
