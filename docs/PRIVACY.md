# 隐私说明 Privacy

Mewview 是一个**纯本地运行**的图片查看工具。以下是它的真实数据行为。

## 数据流向

- **图片**：仅在本地打开、显示与处理，**不会上传**到任何服务器。
- **OCR 内容**：OCR 完全在本地进程内运行（ONNX Runtime），识别出的文字**不会离开本机**。
- **剪贴板**：复制/粘贴操作仅与本机系统剪贴板交互。

## 网络行为

Mewview **不进行任何后台联网**。唯一的网络访问是：

- **OCR 模型首次下载**：当用户主动点击 OCR 且模型尚未安装时，程序会弹窗询问，经用户确认后才从 RapidOCR 官方模型源下载模型（约 36 MB），并缓存到 `%LOCALAPPDATA%\Mewview\models`。此后不再联网。

## 不收集的内容

- 无遥测 / 无分析
- 无账户 / 无登录
- 无自动更新检查
- 无崩溃上报（异常仅写入本地日志 `%TEMP%\mewview_error.log`）
- 无图片内容或 OCR 文本的收集

## 本地数据

- OCR 模型缓存：`%LOCALAPPDATA%\Mewview\models`
- 错误日志：`%TEMP%\mewview_error.log`

用户可随时删除以上目录/文件。
